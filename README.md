# Sensitive-annlysis
Implementation of Global Activity Scores (GAS) for global sensitivity analysis, including parameter sampling, model evaluation, activity score computation, and visualization of parameter importance.

## Projects

- [`gas_neural_network/`](gas_neural_network/) — a reproducible experiment applying GAS to global input sensitivity of a trained ReLU neural network, with matched-budget Sobol and DGSM baselines and a common-random-number noise audit.
